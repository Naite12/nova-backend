# N.O.V.A. Backend — Deploy on Railway

## Steps:

1. Go to https://railway.app and create free account
2. Click "New Project" → "Deploy from GitHub"
3. Or use "Deploy from local" and upload this folder
4. Set environment variable: PORT=3001
5. Railway gives you a URL like: https://nova-backend.up.railway.app

## Then update landing.html:
Replace the payment section with the backend URL.
